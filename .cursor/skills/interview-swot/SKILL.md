# Interview SWOT (prospect folder)

## When to use

- User got (or is preparing for) an **interview** at a company that already has a `prospects/<FolderName>/` folder and/or tailored resume.
- User explicitly asks for a **SWOT** or interview tradeoff notes.
- **Do not** run this as part of the default resume/apply workflow.

## Outcome

Write or refresh `prospects/<FolderName>/swot.md`. Optionally give a **short** chat summary (bullets only). Prefer primary sources; label inference; no marketing fluff or unverifiable claims.

## Template

```markdown
# SWOT — <Company> (<Role>)

## Strengths
- …

## Weaknesses
- …

## Opportunities
- …

## Threats
- …

## Notes
- Assumptions or items to verify in interview.
```

## Guidance

- Clear, plain language. Separate **facts** from **opinion**.
- Ground in the posting, `prospects/<FolderName>/job.md` if present, the tailored resume, and fresh research as needed.
- Keep SWOT useful for **interview prep** (what to emphasize, what they may probe, questions to ask)—not a second résumé.
- If the prospect folder or company name is unclear, ask once; otherwise match existing `prospects/` naming.
